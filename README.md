# 赤電 CRIMSON BOLT

瀏覽器 3D 縱向捲軸射擊遊戲，致敬 1990 年代的經典街機射擊：五個關卡、四種主武器與三種副武器、清場炸彈、勳章連鎖、用 CR（信用點數）購買機型／塗裝／永久強化的機庫，以及本機排行榜。
名稱、美術、音樂全部原創；3D 模型、地形、音效與配樂（節奏強烈的戰鬥風格）都是程式即時產生，沒有任何圖檔或音檔。

**線上遊玩：https://alan00205-creator.github.io/crimson-bolt/** （手機、電腦都能直接開）

## 怎麼玩

| | 手機（直式） | 電腦鍵盤 | 手把 |
|---|---|---|---|
| 移動 | 畫面下方中央的**虛擬搖桿**（推得越遠飛得越快；搖桿以外的地方不會移動戰機） | 方向鍵／WASD | 左搖桿／十字鍵 |
| 慢速（精準閃避） | 輕推搖桿（推得越少越慢） | 按住 Shift | 按住 LB／LT／RT |
| 僚機收攏（PHANTOM） | 按住 B 鈕上方的 **集中** 鈕 | 按住 Shift | 按住 LB／LT／RT |
| 射擊 | 自動 | 自動 | 自動 |
| 炸彈 | 右下角 **B** 鈕 | X／空白鍵 | B／X／RB |
| 暫停 | 右上角 ‖（手機返回鍵、轉橫向也會自動暫停） | Esc／P | Start |
| 靜音 | 設定頁 | M（設定會記住） | 設定頁 |
| 選單 | 點按 | ↑↓ 選擇、Enter 確定、Esc 返回 | 十字鍵、A 確定、B 返回 |
| 機庫切換分頁 | 點分頁 | ←→ 或 Q／E | LB／RB 或十字鍵左右 |

介面依裝置自動切換，不必設定：
- **手機／平板**：顯示下方搖桿與 B 鈕。設定頁可調「搖桿速度」（慢／標準／快）。
- **電腦**：搖桿與 B 鈕隱藏，畫面下方改成按鍵說明列，標題畫面按 Enter 即出擊。滑鼠只用來點選單，**不會**移動戰機。
- 觸控筆電、平板接鍵盤這類兩種都有的裝置：碰螢幕就切成觸控介面，按方向鍵（或動手把）就切回鍵盤介面，遊戲中也能即時切換。
- 嵌在別的網頁裡（例如預覽框）時，瀏覽器要先點一下畫面才會把按鍵送進來；標題畫面會出現黃字提醒。

流程：標題 →（機庫選機、換塗裝、買強化）→ 第 1 關 → 第 2 關 → 第 3 關 → 第 4 關 → 第 5 關（最終關）→ 全破結算 → 第二輪（難度提升）。
每關打完都有結算畫面（評等 S/A/B/C），按「下一關」繼續。中途全滅可接關：分數歸零，但從**當下這一關**原地繼續，已賺到的 CR 不會消失。
最高分、排行榜、CR 與已購買的機型／塗裝／強化都存在瀏覽器本機（localStorage）；換手機或清除瀏覽器資料就會歸零。

## 關卡

| 關卡 | 地形 | 中頭目 | 頭目 |
|---|---|---|---|
| 1 沿岸前線 COASTAL FRONT | 海洋 → 海岸 → 田野 → 城市 → 空軍基地 | 地面履帶砲車 | 巨大空中要塞 ARCLIGHT |
| 2 灼熱峽谷 SCORCHED CANYON | 沙丘 → 峽谷 → 台地 → 煉油廠 → 沙漠要塞 → 乾湖 | 六足步行砲台 SCORPION | 陸上戰艦 BEHEMOTH（三階段） |
| 3 天空要塞 SKY CITADEL | 雲海上空：晴空 → 暴風雲 → 金色高空 → 近太空（只有空中敵機） | 護衛巡洋艦 VALKYRIE | 空中母艦 SERAPH（三階段） |
| 4 冰原戰線 FROZEN FRONTIER | 浮冰海 → 冰河峽灣 → 破冰航道 → 極地海軍基地 → 雪原要塞 → 冰封湖面 | 破冰戰艦 ICEBREAKER | 極地要塞 NORTHSTAR（三階段） |
| 5 軌道決戰 ORBITAL FINALE | 地球軌道：地球光 → 殘骸風暴 → 敵方軌道站 → 核心決戰區（只有空中敵機） | HYDRA | 終焉之核 OMEGA（最終頭目） |

每關約 3～4 分鐘，關卡越後面越難（每關難度約提升第二輪的三分之一）。第 2～5 關有各自的新敵人（例如第 2 關的武裝直升機、多管火箭車、氣墊快艇，第 3 關的攔截機、飛行巡防艦、衝鋒機、布雷機），也會出現前面關卡的部分敵機。打倒第 5 關的 OMEGA 就是全破，接著從第 1 關開始下一輪。

## 武器

**主武器**（撿 P 道具；P 會在四種顏色間輪替，撿到什麼顏色就換成那種武器，而且每撿一個火力都升一級，最高 Lv8；已滿級再撿同色得 5,000 分）

| 顏色 | 名稱 | 特性 |
|---|---|---|
| 紅 | VULCAN 散射火神砲 | 扇形散射，涵蓋範圍大 |
| 藍 | LASER 雷射 | 直線高單體傷害 |
| 粉紅 | PLASMA 電漿鎖定光束 | 自動鎖定前方目標、光束會彎過去；等級越高可同時鎖定越多目標（最多 3 個），單體傷害略低 |
| 金 | WAVE 穿透波動砲 | 月牙形波動，會貫穿敵人、每個敵人只打一次，適合清場 |

**副武器**（撿 S 道具；H → N → M 輪替，換副武器同樣會升一級，最高 Lv4）：HOMING 追蹤飛彈、NUKE 核子飛彈（命中爆炸範圍傷害）、MULTI 散射飛彈（扇形直射火箭）。

**炸彈**（B 道具）：清除畫面敵彈並短暫無敵。

## 金錢（CR）與機庫

- 每 40 分換 1 CR；第 1～5 關過關另有 1,500／2,500／4,000／5,500／7,500 CR。
- CR 在每關結算、遊戲結束、從暫停選單離開、以及關掉分頁時存入錢包；同一局不會重複入帳。
- 標題畫面的 **HANGAR 機庫** 有三個分頁（鍵盤 ←→ 或 Q／E、手把 LB／RB 切換）。購買都要再按一次確認；CR 不夠會直接說還差多少。

**機體**：購買與切換出擊機，點選時背景會預覽該機。

| 機型 | 價格 | 特性 |
|---|---|---|
| 赤電 CRIMSON BOLT | 免費 | 均衡型 |
| 疾風 GALE | 8,000 CR | 速度最快、中彈判定最小、擦彈範圍最大；火力 ×0.9、炸彈 2 顆 |
| 重鎚 TITAN | 15,000 CR | 火力 ×1.3、炸彈 4 顆、開局火力 Lv2；速度慢、判定大 |
| 幻影 PHANTOM | 30,000 CR | 兩架僚機跟著射擊（招式隨主武器變化）；按住慢速或「集中」鈕時僚機收攏、集中火力 |

## 排行榜

- 標題畫面的 **RANKING 排行榜**：這台裝置的前 10 名，顯示名字、分數、機型（塗裝色塊）、到達的輪數與關卡（「2-3」＝第 2 輪第 3 關）、全破標記（打完最終關；舊版三關時代的紀錄則是打完第 3 關）、接關次數與日期；最新的一筆會標亮。
- 一局結束時才記錄，而且每局只記一次：GAME OVER（不接關）、從暫停選單 QUIT／RESTART（分數大於 0 才算）、以及結算或全破畫面按 TITLE。按「下一關／下一輪」、切到別的分頁或關掉畫面都不算結束。分數以這一局的最高分計（接關會把分數歸零，但最高分保留）。
- 標題的 HI-SCORE 就是排行榜第一名的分數（舊版存下的最高分如果比較高，會保留）。停在結算畫面就關掉的那一局還沒結束，所以不會留下最高分。
- 進入前 10 名會請你輸入名字（最多 10 字，預設為上次用的名字，第一次是 PLAYER）：Enter／OK 確定，Esc／手把 B 保留預設名字，手把直接按 A 也行；手機點一下輸入框就會跳出鍵盤。
- 「清除」鈕要再按一次確認，會同時清掉排行榜與最高分。紀錄只存在這台裝置，不會上傳。

## 執行方式

ES modules 不能用 `file://` 直接開，兩種方式擇一：

```bash
# A. 開發用：任何靜態伺服器
python3 -m http.server 8000     # 在倉庫根目錄執行
# 瀏覽器開 http://localhost:8000/        （加 #debug 會掛上除錯指令 window.__cb）

# B. 單一檔案版：打包成一個 HTML，可直接雙擊開啟
node tools/build.mjs        # → dist/crimson-bolt.html
```

three.js（r170）從 jsdelivr CDN 載入，所以**第一次開啟需要網路**。

js/game.js        遊戲核心：玩家與機型數值、敵人、子彈、道具、碰撞、計分；View = 鏡頭與座標換算

js/input.js       鍵盤、虛擬搖桿（觸控）、手把
js/ui.js          HUD、橫幅、得分浮字、結算動畫、機庫分頁、排行榜

座標約定：遊戲平面在 y = 0（玩家、空中敵機、所有子彈），地面在 y = −6（坦克、砲台、船）。
地面單位的判定位置是「沿鏡頭射線投影到遊戲平面」的位置，所以看起來打到哪裡就是打到哪裡。

## 效能

- 所有子彈、光束與粒子走 6 個 instanced 批次（約 6 次 draw call）；五關的所有模型開機時就建好放進物件池並預先編譯 shader，不在遊戲中途建立。
- 自動畫質：手機預設中畫質（像素比 ≤ 1.5 + Bloom），連續兩個 3 秒視窗平均低於 48 fps 就降一級，最低一級關掉 Bloom、像素比 1、地形簡化。設定頁可手動固定 HIGH／LOW。
- 失焦、切換分頁、來電時自動暫停並暫停音訊。
