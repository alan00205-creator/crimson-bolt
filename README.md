# 赤電 CRIMSON BOLT

瀏覽器 3D 縱向捲軸射擊遊戲，致敬 1990 年代的經典街機射擊（紅藍武器切換、追蹤／核子飛彈、清場炸彈、勳章連鎖、地面坦克與巨大要塞 Boss）。
名稱、美術、音樂全部原創；3D 模型、地形、音效與配樂都是程式即時產生，沒有任何圖檔或音檔。

> 這個資料夾與 mi-buddy 的其他部分（`bot/`、`site/`、`web/`）**完全無關、零相依**。
> 放在 `site/` 以外是刻意的：推 master 不會把它部署到 stockmibuddy.com，也不會碰到官網的 CSP 檢查。

## 怎麼玩

| | 手機（直式） | 電腦鍵盤 | 手把 |
|---|---|---|---|
| 移動 | 畫面下方中央的**虛擬搖桿**（推得越遠飛得越快；搖桿以外的地方不會移動戰機） | 方向鍵／WASD，按住 Shift 慢速移動 | 左搖桿／十字鍵 |
| 射擊 | 自動 | 自動 | 自動 |
| 炸彈 | 右下角 **B** 鈕 | X／空白鍵 | B／X／RB |
| 暫停 | 右上角 ‖（手機返回鍵、轉橫向也會自動暫停） | Esc／P | Start |
| 選單 | 點按 | ↑↓ 選擇、Enter 確定、Esc 返回 | 十字鍵、A 確定、B 返回 |

介面依裝置自動切換，不必設定：
- **手機／平板**：顯示下方搖桿與 B 鈕。設定頁可調「搖桿速度」（慢／標準／快）。
- **電腦**：搖桿與 B 鈕隱藏，畫面下方改成按鍵說明列，標題畫面按 Enter 即出擊。滑鼠只用來點選單，**不會**移動戰機。
- 觸控筆電、平板接鍵盤這類兩種都有的裝置：碰螢幕就切成觸控介面，按方向鍵（或動手把）就切回鍵盤介面，遊戲中也能即時切換。
- 嵌在別的網頁裡（例如預覽框）時，瀏覽器要先點一下畫面才會把按鍵送進來；標題畫面會出現黃字提醒。

流程：標題 → 第 1 關「沿岸前線」（海洋 → 海岸 → 田野 → 城市 → 空軍基地，約 4 分鐘）→ 中頭目 → 巨大要塞 ARCLIGHT → 結算（評等 S/A/B/C）→ 可進第二輪（難度提升）。
中途全滅可接關（分數歸零，從原地繼續）。最高分存在瀏覽器本機。

## 執行方式

ES modules 不能用 `file://` 直接開，兩種方式擇一：

```bash
# A. 開發用：任何靜態伺服器
cd game/crimson-bolt && python3 -m http.server 8000
# 瀏覽器開 http://localhost:8000/        （加 #debug 會掛上除錯指令 window.__cb）

# B. 單一檔案版：打包成一個 HTML，可直接雙擊開啟
node tools/build.mjs        # → dist/crimson-bolt.html
```

three.js（r170）從 jsdelivr CDN 載入，所以**第一次開啟需要網路**。

## 程式結構

```
index.html      版面、HUD、選單、import map（three.js）
js/main.js      開機、渲染器與 Bloom 後製、自動畫質、狀態機（標題／遊戲／暫停／接關／結算）
js/game.js      遊戲核心：玩家、武器、敵人、子彈、道具、碰撞、計分；View = 鏡頭與座標換算
js/stage.js     敵人數值表、各敵人 AI、中頭目、Boss、第 1 關時間軸（以捲動距離觸發）
js/fx.js        instanced 粒子／子彈批次繪製、爆炸配方、3D 碎片、畫面震動
js/input.js     鍵盤、虛擬搖桿（觸控）、手把
js/ui.js        HUD、橫幅、得分浮字、結算動畫
js/models.js    所有 3D 模型（程式產生的低多邊形）
js/world.js     捲動地形：六種地貌、水面 shader、雲層、時間推移的光線
js/audio.js     WebAudio 合成音效與配樂
dev/*.html      各模組的預覽／測試頁（模型展示、地形、音效面板）
tools/build.mjs 單一檔案打包
```

座標約定：遊戲平面在 y = 0（玩家、空中敵機、所有子彈），地面在 y = −6（坦克、砲台、船）。
地面單位的判定位置是「沿鏡頭射線投影到遊戲平面」的位置，所以看起來打到哪裡就是打到哪裡。

## 效能

- 所有子彈與粒子走 5 個 instanced 批次（約 5 次 draw call）；模型用物件池重複使用，不在遊戲中途建立。
- 自動畫質：手機預設中畫質（像素比 ≤ 1.5 + Bloom），連續兩個 3 秒視窗平均低於 48 fps 就降一級，最低一級關掉 Bloom、像素比 1、地形簡化。設定頁可手動固定 HIGH／LOW。
- 失焦、切換分頁、來電時自動暫停並暫停音訊。
